# HTML5 Semantic Structure & Accessibility

Created by Chinmay C for the Thiranex web development assignments.

## Start
Open `index.html` in a browser (for ES module projects use `python -m http.server 8000`).

## Features
- Four semantic pages with headings, navigation and landmarks
- SEO metadata and responsive viewport
- Accessible validated contact form (mailto draft)
- Keyboard-friendly focus states
